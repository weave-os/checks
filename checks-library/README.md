# Checks library

These checks are optional examples, not universal defaults. Each may make sense in certain circumstances, depending on your repository's policies, product, and tech stack. Review the criteria and copy only the checks that apply into your configured checks directory; enabling this entire directory runs all three.

- **User Prompt Privacy** — for repositories that need to prevent captured user requests or conversation excerpts from being committed.
- **No Checked-in Specs** — for teams that intentionally keep implementation specifications outside version control.
- **Mobile Layout** — for repositories with page-level UI that needs responsive mobile behavior.

Adapt the criteria to your own workflow before using them. The action does not enable these checks automatically.
